# 🌐 Webアプリケーション開発ポートフォリオ（Java / JSP / Servlet）

## 📘 概要
Java / JSP / CSS を用いて開発した Web アプリケーションです。  
フラワーサロンの運営サイトを学習目的で作成しました。

---

## 🛠 開発環境
| 項目 | 内容 |
|------|------|
| 言語 | html / Java / CSS / JavaScript|
| フレームワーク | Servlet / JSP |
| データベース | MySQL 8.0 |
| ビルドツール | Apache Maven または Eclipse Dynamic Web Project |
| アプリケーションサーバー | Apache Tomcat 10.x |
| 開発環境| Eclipse / VS Code |
| バージョン管理 | GitHub |
| OS | macOS / Windows |
